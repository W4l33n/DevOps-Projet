5. Workflow
Pour le projet nous avons décidé de faire des branches pour chaque fonctionnalités par exmple une branche pour l'intégration continue, une branche pour créer la bibliothèque java et ainsi de suite. Pour la validation il faut au moins qu'une personne fasse une revue du code que quelqu'un souhaite mergé sur une branche autre que le main. Pour la branche main toute l'équipe doit être au courant des changements à apporter et font une revue du code.
